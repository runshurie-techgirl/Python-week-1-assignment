# Python-week-1-assignment

My first Python program: a short self-introduction using variables and the `print()` function.

## What the program does

`All about me.py` stores four details about me in variables (`name`, `age`, `favourite_language`, and `goal`) and displays them using `print()` with f-strings.

## How to run it

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

```
python "All about me.py"
```

(If that doesn't work, try `py "All about me.py"`. The quotes are needed because the file name has spaces.)

 Expected output

```
Hello! My name is Run Hajir.
I am 19 years old.
My favourite language is Python.
My goal for this course is to learn Python well enough to build AI and automation tools that solve real problems for businesses and communities in Kenya.
```

 Concepts practised

- Creating variables
- Using `print()` and f-strings
- Writing `#` comments
